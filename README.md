# why-are-we-here
让需求得到实现的技能是什么？我觉得底层的是拆解整合或者说分析的能力。像是生成一张“感到不安的生成式海报”，从美术的角度，你需要拆解参考图的画风、构图、物体结构；需要拆解“让人感到不安”是什么造成的等等。从程序的角度，你需要分析哪些提示词是有效的；哪种模型能带来更好的效果；甚至是如何才能更省token……这些都要依靠拆解整合的技能。之所以我觉得这个能力是重点，是因为让ai帮你做点什么的时候，使用的是自然语言，对吧？很多人就像聊天一样给ai说，嘿，我要一张图，这张图给人的感觉是让人不安的。但是这种需求的表述无疑是模糊的，设身处地想一下，如果我的老板给我了这样一个模糊的需求，且不给任何附加的说明，我也会很崩溃，不知道应该怎么做。因此我觉得在给ai提出需求的时候，你需要拆解整合，让你的需求足够具体和清晰。我想这就是从这个需求中得到你真正想要的东西的方法。
