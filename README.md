# why-are-we-here
让需求得到实现的技能是什么？我觉得底层的是拆解整合或者说分析的能力。像是生成一张“感到不安的生成式海报”，从美术的角度，你需要拆解参考图的画风、构图、物体结构；需要拆解“让人感到不安”是什么造成的等等。从程序的角度，你需要分析哪些提示词是有效的；哪种模型能带来更好的效果；甚至是如何才能更省token……这些都要依靠拆解整合的技能。之所以我觉得这个能力是重点，是因为让ai帮你做点什么的时候，使用的是自然语言，对吧？很多人就像聊天一样给ai说，嘿，我要一张图，这张图给人的感觉是让人不安的。但是这种需求的表述无疑是模糊的，设身处地想一下，如果我的老板给我了这样一个模糊的需求，且不给任何附加的说明，我也会很崩溃，不知道应该怎么做。因此我觉得在给ai提出需求的时候，你需要有拆解整合的技能，让你的需求足够具体和清晰。我想这就是从这个需求中得到你真正想要的东西的方法。
如果不了解你所使用的媒介，代价会是什么？我觉得与其说可能性，不如说潜力？对一个媒介了解的越深入，你就越了解它可以做到什么地步。
ai的争议在ai使用的各个领域里，反对的更激烈的地方往往是艺术领域，或者说是，创意领域。就像在学生时期，抄作文一向比抄数学或者物理作业答案更让人难以接受吧？我觉得人们在ai领域也是一样的。
说回正题，我希望从“艺术创作的过程”角度来讨论这个问题。创作的过程伴随着舍弃一些什么，再保留一些什么，从几个选项里保留其中之一……重复上万次。正是这些成千上万次的“决策”，构成了一个作品，以及一个作品属于谁。可以说，创作的过程就是决策的过程。一张图片，或者一篇小说，它的艺术性和主观性，往往来自于它的创作过程中，包含着创作者成千上万次的个人选择。我觉得ai生成之所以构成争议的原因就是，它把决策减少到了稀少的量级————如果一张图原本需要上万次决策才能画出来，而使用ai之后，寥寥数十次决策就把这张图生成了，那么这张图，它真的能体现使用ai的那个人的自身的艺术性和主观性吗？尤其是ai的模型往往由数十万张画作训练而成，作为训练素材的每张图都是那个创作者通过数万次决策创作出来的。寥寥数十次的决策，它呈现的不是使用ai的那个人想要表达的东西，它呈现的是模型里训练素材的艺术家们的决策的集合。
因此我认为，人在一件作品里的决策数量决定了这个作品是否属于那个人。而“了解该系统的运作原理”我觉得它不能直接改变署名权，它像是，帮助人们发现更多作品创作中可能存在的，可以决策的地方。随着决策数量的上升，作品的个体性也会随之凸显，而署名权的争议也会减少。
